# MPI Jelajah Gaya — GitHub Pages

Folder ini sudah disiapkan untuk GitHub Pages.

## Cara upload
1. Buat repository GitHub baru.
2. Upload **isi folder ini** (bukan file ZIP) ke root repository: `index.html`, folder `assets`, `.nojekyll`, dan file lain.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu simpan.

Aset Base64 dari HTML asli sudah dipindahkan ke folder `assets/` agar tidak ada satu file besar yang melewati batas upload.
